MIDNIGHT MARKET — an original spot-the-difference game set in a rainy Japanese night market. Two near-identical panels, 8 hidden differences, markers on every find, a 3-minute timer, 3 hints, synthesized sound effects, and full keyboard play. All art is original SVG drawn in code; no external assets, no network requests.

## Run it

Serve the game locally and open it in desktop Chrome:

```sh
node serve.ts
```

Then open http://localhost:8080. Or hand it in with the entry program:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
